# 🎯 Section 3: Classification

Predicting a category: will this user buy after seeing an ad? Nine notebooks on the same dataset, from logistic regression to tuned ensembles.

> 📂 The notebooks read their data from `../data/`: open them from this folder in Jupyter (the default) and the paths resolve.

| # | Notebook | What it covers | Dataset |
|:-:|----------|----------------|---------|
| 1 | [`01-logistic-regression.ipynb`](01-logistic-regression.ipynb) | Logistic regression | `data/social-network-ads.csv` |
| 2 | [`02-support-vector-machine.ipynb`](02-support-vector-machine.ipynb) | Support Vector Machine with cross-validation and evaluation metrics | `data/social-network-ads.csv` |
| 3 | [`03-kernel-svm.ipynb`](03-kernel-svm.ipynb) | Kernel SVM | `data/social-network-ads.csv` |
| 4 | [`04-svm-performance-analysis.ipynb`](04-svm-performance-analysis.ipynb) | SVM performance analysis: cross-validation and metrics | `data/social-network-ads.csv` |
| 5 | [`05-naive-bayes.ipynb`](05-naive-bayes.ipynb) | Naïve Bayes: GaussianNB, BernoulliNB and ComplementNB compared | `data/social-network-ads.csv` |
| 6 | [`06-decision-tree-classification.ipynb`](06-decision-tree-classification.ipynb) | Decision tree classifier | `data/social-network-ads.csv` |
| 7 | [`07-random-forest-classification.ipynb`](07-random-forest-classification.ipynb) | Random forest classifier | `data/social-network-ads.csv` |
| 8 | [`08-knn-rf-gb-performance-evaluation.ipynb`](08-knn-rf-gb-performance-evaluation.ipynb) | KNN, random forest and gradient boosting evaluated side by side | `data/social-network-ads.csv` |
| 9 | [`09-tuning-and-cross-validation-gb-rf.ipynb`](09-tuning-and-cross-validation-gb-rf.ipynb) | Grid-search tuning and cross-validation for KNN, gradient boosting and random forest | `data/social-network-ads.csv` |
